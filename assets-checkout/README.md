# Artes para o checkout

| Arquivo | Dimensão |
| --- | --- |
| `23-banner-checkout.png` | 1200 × 675 |
| `23-banner-checkout-1200x600.png` | 1200 × 600 |
| `23-banner-checkout-960x288.png` | 960 × 288 |
| `23-banner-checkout-1080x1080.png` | 1080 × 1080 |

As versões 1200 × 675 e 1200 × 600 foram recompostas a partir da arte oficial para que o título inteiro caiba. As outras duas vieram do ZIP.

As quatro mostram o kit completo e mencionam acesso após confirmação do pagamento. Antes de enviar qualquer uma delas à plataforma, confirme os sete bônus da oferta, o fluxo de entrega e qual dimensão o painel aceita. Os PNGs ficam fora da pasta publicada pelo Vite.
